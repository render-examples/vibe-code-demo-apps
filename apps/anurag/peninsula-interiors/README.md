# peninsula-interiors

A brochure-style website for a Bay Area Peninsula interior design studio. Since the site only needs to showcase portfolio work, services, and contact info with no server-side data changes, a single static site is sufficient — no backend or database is warranted.

Generated by the Vibe Code factory from the prompt: "Create a website for an interior designer in the Peninsula, Bay Area"

## Infrastructure

- static_site

## Deploying this app on its own

It is already deployed as part of the factory's Blueprint at the
repository root. To run it as its own Blueprint instead, create a new
Blueprint from https://github.com/render-examples/vibe-code-demo-apps with the Blueprint Path set to:

```text
apps/anurag/peninsula-interiors/render.yaml
```
