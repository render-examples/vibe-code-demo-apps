# marin-silent-retreat

A one-day silent yoga retreat in Marin County on December 2, 2026 needs a simple, calm landing page presenting the schedule, location, pricing, and a registration call-to-action. Since there's no need for accounts, persistent user data, or server-side logic (registration can link out to email or an external form/payment link), a single static site fully serves this brief with no backend or database required.

Generated by the Vibe Code factory from the prompt: "Create a website for a silent yoga retreat in Marin for December 2, 2026."

## Deploying this app on its own

It is already deployed as part of the factory's Blueprint at the
repository root. To run it as its own Blueprint instead, create a new
Blueprint from https://github.com/render-examples/vibe-code-demo-apps with the Blueprint Path set to:

```text

```
