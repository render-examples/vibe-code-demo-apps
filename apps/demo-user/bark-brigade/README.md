# bark-brigade

A brochure-style website for 'Bark Brigade,' a whimsical volunteer firefighter program for dogs. The site introduces the program, showcases dog 'recruits' and their ranks/badges, explains how to volunteer a dog, and shares training milestones. Since all content is fixed at launch (program info, dog roster, FAQs) and there's no need for persistent user-submitted data, accounts, or transactions, a single static_site is the smallest primitive that fully serves this prompt.

Generated by the Vibe Code factory from the prompt: "create a website for a volunteer firefighter program for dogs."
