# masa-fuego-tacos

A single-page brochure site for "Masa Fuego," a taco food truck. The prompt asks only for a landing page — there's no user data, orders, or accounts to persist, and nothing needs to run server-side per request. A static site fully serves this: it shows the menu, hours, live location, and a call-to-action to follow on social/text for the daily spot. No web_service, postgres, or key_value is justified since there's no dynamic data lookup, no form processing that requires a backend, and nothing that outlives a single page load.

Generated by the Vibe Code factory from the prompt: "Create a website landing page for a taco food truck"

## Deploying this app on its own

It is already deployed as part of the factory's Blueprint at the
repository root. To run it as its own Blueprint instead, create a new
Blueprint from https://github.com/jacobprall/airo-apps with the Blueprint Path set to:

```text
apps/demo-user/masa-fuego-tacos/render.yaml
```
