# synthwave-collective

A static brochure/community site for synth enthusiasts covering vintage and modern synthesizers, a browsable gear catalog, patch tips, and event listings. Everything is read-only reference content (no accounts, orders, or server-side data changes), so a single static site fully serves the prompt with in-browser filtering for the gear catalog.

Generated by the Vibe Code factory from the prompt: "Create a website for synth enthusiasts"

## Infrastructure

- vibe-demo-user-synthwave-collective-web (static)

## Deploying this app on its own

It is already deployed as part of the factory's Blueprint at the
repository root. To run it as its own Blueprint instead, create a new
Blueprint from https://github.com/render-examples/vibe-code-demo-apps with the Blueprint Path set to:

```text
apps/demo-user/synthwave-collective/render.yaml
```
