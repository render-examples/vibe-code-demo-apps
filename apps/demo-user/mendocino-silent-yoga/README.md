# mendocino-silent-yoga

A single-day silent yoga retreat in Mendocino County (Dec 2, 2026) is a straightforward marketing/registration landing page — no accounts, transactions, or data that changes post-launch beyond what can be handled with a simple external form link. A static site alone covers the itinerary, pricing, location, FAQ, and a call-to-action to reserve a spot (via an embedded/external form or email), so no backend or database is warranted.

Generated by the Vibe Code factory from the prompt: "Create a website for a silent yoga retreat in Mendocino County on Dec 2, 2026."
