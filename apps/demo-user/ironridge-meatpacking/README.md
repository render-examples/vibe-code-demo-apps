# ironridge-meatpacking

A brochure-style website for Ironridge Meat Packing Co., a wholesale meat processing plant. The site presents the company's history, USDA certifications, product line (beef, pork, poultry cuts), wholesale ordering info, and contact/location details. Since all content is static company information and a read-only product catalog with no per-request logic, transactions, or data that changes after deployment, a single static_site is sufficient — filtering of the product catalog can be done client-side in the browser.

Generated by the Vibe Code factory from the prompt: "Create a website for a meat packing plant"
