# ironvale-meats

A brochure-style website for Ironvale Meats, a family-run meat-packing plant. The prompt asks for a "basic website," so the plan is a single static site: no user data needs to persist between visits and nothing needs to run per-request, so a web service and database would be unjustified overhead. The site covers who the plant is, what cuts/products it packs, its safety and USDA-inspection credentials, and how wholesale buyers or retail customers can get in touch.

Generated by the Vibe Code factory from the prompt: "Create a basic website for a meat-packing plant"
