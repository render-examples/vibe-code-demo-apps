# gloomy-tails

A whimsical static website for 'depressed dogs' seeking help from canine mental health specialists. This is a lighthearted directory/brochure site listing specialists, their bios, and approaches, plus a light-up-your-day resource section. Since all content (specialist profiles, articles, contact info) is fixed and doesn't require accounts, transactions, or data that changes post-deploy, a single static_site is sufficient — no backend or database needed.

Generated by the Vibe Code factory from the prompt: "create a website for depressed dogs to get help from specialists"

## Infrastructure

- vibe-demo-user-gloomy-tails-web (static)

## Deploying this app on its own

It is already deployed as part of the factory's Blueprint at the
repository root. To run it as its own Blueprint instead, create a new
Blueprint from https://github.com/render-examples/vibe-code-demo-apps with the Blueprint Path set to:

```text
apps/demo-user/gloomy-tails/render.yaml
```
