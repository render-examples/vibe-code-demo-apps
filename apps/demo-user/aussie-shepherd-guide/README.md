# aussie-shepherd-guide

A static informational website about Australian Shepherds covering breed history, temperament, appearance, coat colors, exercise and grooming needs, health, and training tips. Since this is read-only editorial content with no user accounts, transactions, or data that changes after deployment, a single static_site is the smallest sufficient primitive — all content and any filtering (e.g., by coat color) can be handled client-side in the browser.

Generated by the Vibe Code factory from the prompt: "Create a website that includes information on Australian Shepherds."

## Infrastructure

- vibe-demo-user-aussie-shepherd-guide-web (static)

## Deploying this app on its own

It is already deployed as part of the factory's Blueprint at the
repository root. To run it as its own Blueprint instead, create a new
Blueprint from https://github.com/render-examples/vibe-code-demo-apps with the Blueprint Path set to:

```text
apps/demo-user/aussie-shepherd-guide/render.yaml
```
